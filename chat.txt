---

## 一、 演算法實作原理

在 Cliff Walking 環境中，兩者的更新公式如下：

### 1. Q-learning (Off-policy)
更新時假設未來會採取**最優動作**，而不考慮實際探索時可能發生的失誤：
$$Q(S, A) \leftarrow Q(S, A) + \alpha [R + \gamma \max_a Q(S', a) - Q(S, A)]$$

### 2. SARSA (On-policy)
更新時基於**實際採取**的下一個動作 $A'$，這意味著它會把「探索（$\epsilon$-greedy）」導致的風險納入價值評估：
$$Q(S, A) \leftarrow Q(S, A) + \alpha [R + \gamma Q(S', A') - Q(S, A)]$$

---

## 二、 訓練結果分析

### （一） 學習表現與收斂速度
*   **累積獎勵曲線：** 
    *   **Q-learning** 在訓練初期的累積獎勵通常比 SARSA 更低（波動更劇烈），因為它執著於走懸崖邊的最短路徑，在存在 $\epsilon$ 探索的情況下，極易掉入懸崖。
    *   **SARSA** 的曲線相對平滑，且最終在訓練期間獲得的「平均獎勵」通常高於 Q-learning。
*   **收斂速度：** Q-learning 學習的是 $Q^*$（最優價值函數），通常能較快找到理論上的最短路徑，但其「在線表現（Online Performance）」較差。

### （二） 策略行為比較 (Final Policy)
經過 500 回合訓練後，兩者學習到的路徑通常如下：

| 特性 | Q-learning (冒險家) | SARSA (保守派) |
| :--- | :--- | :--- |
| **路徑選擇** | 緊貼懸崖邊緣的最短路徑 (Bottom row + 1) | 繞遠路，選擇遠離懸崖的上方路徑 |
| **路徑長度** | 13 步 (最優解) | 15~17 步 (次優解) |
| **行為邏輯** | 認為自己總能選到最好的，忽略 $\epsilon$ 的隨機性。 | 意識到自己偶爾會「手滑」($\epsilon$)，故遠離危險。 |

### （三） 穩定性分析
*   **波動程度：** Q-learning 波動極大。即使 Q 表已經收斂，由於 $\epsilon=0.1$ 的存在，它仍有 10% 的機率執行隨機動作，一旦在懸崖邊隨機移動，就會觸發 -100 的懲罰。
*   **探索的影響：** 對於 SARSA 而言，探索率 $\epsilon$ 是策略的一部分；對於 Q-learning，探索只是為了找尋最優解的手段。

---

## 三、 理論比較與討論

### 為什麼 Q-learning 學習到了最優策略，獎勵卻比較低？
這是因為 Q-learning 學習的是 **Optimal Policy**，但實驗中評估的是 **$\epsilon$-greedy Policy**。在懸崖環境下，最優路徑容錯率為零。Q-learning 更新時無視 $\epsilon$ 的風險，導致它在訓練過程中不斷掉入懸崖。

### 為什麼 SARSA 選擇繞路？
SARSA 是 On-policy，它在更新時知道自己未來還有 10% 的機率會亂走。為了極大化預期獎勵，它發現「繞遠路」雖然每步多扣 1 分，但比起 10% 掉入懸崖扣 100 分，繞路顯然是更穩健的選擇。

---

## 四、 結論

| 比較項目 | Q-learning | SARSA |
| :--- | :--- | :--- |
| **收斂目標** | 理論最優策略 ($Q^*$) | 考量探索風險後的安全策略 |
| **訓練穩定性** | 較低（頻繁掉入懸崖） | 較高 |
| **收斂速度** | 較快找到最短路徑 | 較慢，需反覆確認安全性 |

````python
import numpy as np
import gymnasium as gym
from collections import defaultdict

class SARSAAgent:
    def __init__(self, env, alpha=0.1, gamma=0.9, epsilon=0.1):
        """
        初始化 SARSA 代理
        - alpha: 學習率
        - gamma: 折扣因子
        - epsilon: ε-greedy 探索率
        """
        self.env = env
        self.alpha = alpha
        self.gamma = gamma
        self.epsilon = epsilon
        self.Q = defaultdict(lambda: np.zeros(env.action_space.n))
        
    def epsilon_greedy(self, state):
        """ε-greedy 動作選擇"""
        if np.random.random() < self.epsilon:
            return self.env.action_space.sample()
        else:
            return np.argmax(self.Q[state])
    
    def train(self, episodes=500):
        """訓練 SARSA 代理"""
        rewards_history = []
        
        for episode in range(episodes):
            state, _ = self.env.reset()
            action = self.epsilon_greedy(state)
            episode_reward = 0
            done = False
            
            while not done:
                # 執行動作
                next_state, reward, terminated, truncated, _ = self.env.step(action)
                done = terminated or truncated
                episode_reward += reward
                
                # 選擇下一個動作（On-policy）
                next_action = self.epsilon_greedy(next_state)
                
                # SARSA 更新：使用實際採取的下一個動作
                self.Q[state][action] += self.alpha * (
                    reward + self.gamma * self.Q[next_state][next_action] - self.Q[state][action]
                )
                
                state, action = next_state, next_action
            
            rewards_history.append(episode_reward)
        
        return rewards_history
    
    def get_policy(self):
        """提取貪心策略"""
        policy = {}
        for state in self.Q.keys():
            policy[state] = np.argmax(self.Q[state])
        return policy
    
    def visualize_policy(self):
        """視覺化最終策略（使用箭頭）"""
        arrows = {0: '↑', 1: '↓', 2: '←', 3: '→'}
        policy = self.get_policy()
        
        # 4x12 的 Cliff Walking 環境
        grid = np.zeros((4, 12), dtype=str)
        
        for state in range(48):
            row, col = state // 12, state % 12
            if state in policy:
                grid[row, col] = arrows[policy[state]]
            else:
                grid[row, col] = '·'
        
        # 標記特殊位置
        grid[3, 0] = 'S'   # 起點
        grid[3, 11] = 'G'  # 終點
        grid[3, 1:11] = 'C' # 懸崖
        
        print("=== SARSA 最終策略 ===")
        for row in grid:
            print(' '.join(row))
        print("\n說明：S=起點 | G=目標 | C=懸崖 | ↑↓←→=推薦動作")

# 主程式
if __name__ == "__main__":
    env = gym.make('CliffWalking-v0')
    agent = SARSAAgent(env, alpha=0.1, gamma=0.9, epsilon=0.1)
    
    print("訓練 SARSA 代理...")
    rewards = agent.train(episodes=500)
    
    # 顯示訓練結果
    print(f"\n平均獎勵（最後50回合）: {np.mean(rewards[-50:]):.2f}")
    
    # 視覺化策略
    agent.visualize_policy()
    
    env.close()
````

**關鍵設計說明：**

1. **On-policy 核心** 🎯：第 43-44 行，SARSA 使用 `next_action`（實際選擇），而非 `argmax`（最優動作）
2. **ε 的防護作用** 🛡️：當 ε=0.1 時，SARSA 會在價值更新中預估「10% 時刻會亂走」的風險
3. **可視化函數** 👀：支援箭頭顯示，易於理解學習的路徑傾向

作業目的
本作業旨在實作並比較兩種經典強化學習演算法——Q-learning 與 SARSA，透過相同環境與參數設定，分析其學習行為、收斂特性以及最終策略差異。

本實驗採用經典的格子世界（Gridworld）問題，亦稱為「Cliff Walking」環境。環境設定如下：

使用一個矩形網格（例如 4 × 12）
