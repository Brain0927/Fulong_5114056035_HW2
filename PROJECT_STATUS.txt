═══════════════════════════════════════════════════════════════════════════════

實驗規模：
• 獨立運行次數：50 次
• 每次訓練回合數：500
• 總實驗回合數：25,000

環境配置：
• 環境：Gymnasium CliffWalking-v1
• 網格大小：4×12（48 狀態）
• 動作空間：4（UP, RIGHT, DOWN, LEFT）
• 獎勵設置：普通 -1, 懸崖 -100, 目標 0

超參數設置：
• 學習率 (α)：0.1
• 折扣因子 (γ)：0.9
• 探索率 (ε)：0.1
• ε-貪心：10% 探索, 90% 利用

實驗結果（最後 50 回合平均）：

│     指標          │ Q-Learn  │ SARSA  │   優勝者   │
├────────────────────┼──────────┼────────┼────────────┤
│ 平均獎勵          │  -49.17  │ -23.56 │ ⭐ SARSA  │
│ 標準差            │   9.04   │  2.86  │ ⭐ SARSA  │
│ 最大獎勵          │  -29.02  │ -18.44 │ ⭐ SARSA  │

主要發現：
✓ SARSA 性能優於 Q-Learning 25.61 分（109% 改善）
✓ SARSA 穩定性提升 68.4%（方差降低）
✓ Q-Learning 樂觀估計導致頻繁掉崖
✓ SARSA 保守策略避免風險區域
